Practice 10: Pygame Games Collection
This repository contains three Python projects developed as part of Practice Work №10. Each project demonstrates core concepts of the Pygame library, including event handling, sprite management, game logic, and User Interface (UI) design.

📁 Projects Overview
1. Racer
A classic arcade racing game where the player must dodge oncoming traffic and collect coins.

Key Features:

Randomized enemy and coin spawning.

Dynamic difficulty (speed increases over time).

Score and Coin counters displayed on screen.

Sprite-based collision detection.

2. Snake
A modern take on the retro "Snake" game with a level-based progression system.

Key Features:

"Smart" food spawning (ensures food doesn't appear inside the snake's body).

Leveling system: Speed increases every 3–4 points.

Custom UI showing current Score and Level.

Boundary and self-collision checks.

3. Paint
A functional drawing tool with a graphical user interface.

Key Features:

Tools: Brush, Rectangle, Circle, and Eraser.

Color Palette: Select colors by clicking on the UI color boxes.

Shape Drawing: Drag and release to draw geometric shapes.

Clear Screen: Quick reset functionality.

🚀 Getting Started
Prerequisites:
Make sure you have Python 3.x and Pygame installed:

Bash
pip install pygame
Installation:
Download the Practice10 folder and ensure the images/ directory is in the same path as your scripts.

Running the Games:
Open your terminal/command prompt and run:

Bash
python racer.py
python snake.py
python paint.py
